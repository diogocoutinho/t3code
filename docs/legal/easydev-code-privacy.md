# Política de Privacidade do EasyDev Code

Última atualização: 23 de novembro de 2026.

Esta política vale para os apps EasyDev Code (iOS, iPadOS, Android, desktop e web) e para o serviço EasyDev Connect, oferecidos pela EasyDev Soluções em Informática Ltda ("EasyDev", "nós").

## Como o EasyDev Code funciona

O EasyDev Code controla agentes de código que rodam em um servidor EasyDev Code instalado por você, no seu computador ou na sua máquina. Seus projetos, código, conversas com os agentes, alterações e terminais ficam nesse servidor. O app conversa diretamente com ele, pela sua rede ou pelo EasyDev Connect. A EasyDev não recebe nem guarda esse conteúdo.

Os agentes usam as contas e assinaturas que você configurou no seu servidor (por exemplo Anthropic ou OpenAI). O que você envia a esses provedores segue as políticas de privacidade de cada um.

## Dados que tratamos

**Conta.** Para usar o EasyDev Connect você cria uma conta com e-mail, ou entra com o Google. Guardamos seu nome, e-mail e o identificador da conta. O login é processado pela Clerk, nossa fornecedora de autenticação.

**Ligação entre app e servidor.** Para o app encontrar seus servidores, o EasyDev Connect guarda quais servidores estão ligados à sua conta e os dados técnicos necessários para encaminhar a conexão. O conteúdo que passa por essa conexão não é guardado.

**Notificações.** Se você ativar as notificações, guardamos o token de notificação do aparelho, um identificador do aparelho e suas preferências de notificação. Usamos esses dados só para avisar quando um agente termina ou precisa de você. As notificações são entregues pelo serviço de notificações da Apple (APNs), e o registro das entregas é mantido pelo tempo necessário para diagnosticar falhas.

**Diagnóstico.** O app pode enviar ao seu próprio servidor identificadores da conta e do aparelho em forma de hash, para que o servidor reconheça o cliente conectado. Esses dados não são enviados à EasyDev.

Não usamos seus dados para publicidade, não os vendemos e não rastreamos você em apps ou sites de terceiros.

## Fornecedores

Usamos Clerk (autenticação), Cloudflare (hospedagem do EasyDev Connect), Neon (banco de dados do EasyDev Connect) o serviço de notificações da Apple e, se você entrar com o Google, o login do Google. Eles tratam os dados apenas para prestar esses serviços.

## Seus direitos

Você pode acessar, corrigir ou excluir seus dados. Para excluir a conta, use a opção de excluir conta no perfil, em Ajustes do app, ou fale conosco. Ao excluir a conta, apagamos os dados da conta, as ligações com servidores e os registros de notificação. Os dados do seu servidor ficam com você e podem ser apagados nele a qualquer momento.

Também atendemos aos direitos previstos na Lei Geral de Proteção de Dados (LGPD).
